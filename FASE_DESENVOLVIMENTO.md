# InfinitySoft - Fase de Desenvolvimento

## Objetivo

Criar a primeira versão visual funcionando no celular.

## Primeira entrega

Um aplicativo simples com:

- Tela inicial
- Tela de cadastro de automação
- Campo para palavra-chave
- Campo para link do produto
- Botão ativar

## Teste inicial

O usuário poderá criar uma automação de exemplo:

Palavra:
quero

Resposta:
Aqui está o link do produto.

## Próximas evoluções

- Banco de dados
- Usuários reais
- Integração com redes sociais
- Pagamentos
- Planos para clientes
