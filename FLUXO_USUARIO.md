# InfinitySoft Social - Fluxo do Usuário

## Primeiro acesso

1. Usuário abre o aplicativo.
2. Cria uma conta.
3. Entra no painel principal.

## Criar uma automação

1. Usuário clica em "Nova automação".
2. Escolhe o produto.
3. Define a palavra-chave.
4. Coloca o link de venda.
5. Ativa a automação.

## Funcionamento

Cliente envia a palavra-chave.

Exemplo:

Cliente:
quero

Sistema:

Olá! 😊
Obrigado pelo interesse.

Aqui está o link do produto:
(link)

## Painel

Usuário acompanha:

- Quantas pessoas solicitaram o produto.
- Quantos links foram enviados.
- Quais produtos têm mais interesse.

## Objetivo

Deixar todo o processo simples para qualquer pessoa.
