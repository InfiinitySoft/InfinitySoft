# InfinitySoft - Tecnologia

## Primeira versão

Criar um protótipo simples que funcione pelo celular.

## Objetivo

Validar a ideia antes de construir uma plataforma completa.

## Recursos iniciais

- Interface simples
- Cadastro de usuário
- Cadastro de produtos
- Criação de palavras-chave
- Respostas automáticas

## Evolução futura

- Aplicativo Android
- Integração com Instagram
- Integração com Facebook
- Integração com TikTok
- Integração com Telegram
- Inteligência artificial

## Prioridade

Facilidade de uso para qualquer pessoa.
