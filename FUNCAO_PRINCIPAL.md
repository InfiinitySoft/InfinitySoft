# InfinitySoft Social

## Função principal

Automatizar o envio de links de produtos.

## Como funciona

1. Usuário cadastra um produto.
2. Usuário escolhe uma palavra-chave.
3. Cliente envia a palavra-chave.
4. Sistema identifica a palavra.
5. Sistema envia automaticamente o link do produto.

## Exemplo

Produto:

Curso de Marketing

Palavra-chave:

quero

Cliente escreve:

quero

Resposta:

Olá! Obrigado pelo interesse.

Aqui está o link para comprar:

(link do produto)

## Objetivo

Facilitar vendas e atendimento para qualquer pessoa.
