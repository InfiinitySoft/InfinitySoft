InfinitySoft

## Objetivo

Criar um aplicativo simples de automação de vendas.

## Função principal

Enviar automaticamente o link de um produto quando o cliente enviar uma palavra-chave.

Exemplo:

Cliente escreve:
"quero"

Sistema responde:
"Segue o link do produto"

## Primeira versão

- Cadastro de usuário
- Login
- Criar automações
- Cadastrar palavra-chave
- Cadastrar link do produto
- Histórico de mensagens
